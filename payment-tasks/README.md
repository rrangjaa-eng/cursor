# 비용 지급 일정 → Google Tasks 자동 등록

공유 드라이브에 올라오거나 수정된 문서와 내 메일함의 새 메일을 15분마다 확인합니다.
견적서 최종 지급액, 대관·임대·용역 계약서의 지급 일정 같은 **나가는 비용**을 찾아
Google Tasks의 **"비용 지급 일정"** 목록에 기한과 함께 등록합니다.

## 동작 방식

```
[15분마다 run()]
 1. 수집   내가 멤버인 모든 공유 드라이브의 변경 파일 + 내 메일함 새 메일(내가 보낸 메일 제외)
 2. 1차 판별 이름에 견적·계약·대관… 키워드가 있거나, 본문에 지급·합계·부가세… + 금액이 있으면 후보
 3. 추출   규칙(무료)으로 금액·기한이 하나씩 분명하면 확정
           → 아니면(PDF·이미지, 분할 지급, "7일 전" 같은 상대 기한, 후보 여러 개) Claude API
           → API 키가 없으면 "[직접 확인]" 할 일
 4. 등록   지급 건마다 할 일 1개 (제목: 상대방·내용·금액, 기한, 메모: 근거 문구·올린 사람·원본 링크)
```

- 같은 문서가 수정돼 금액·기한이 바뀌면 **완료하지 않은** 이전 할 일을 지우고 새로 만듭니다. 완료한 할 일은 그대로 둡니다.
- 한 문서가 3번 연속 처리에 실패하면 "[직접 확인]" 할 일을 남기고 넘어갑니다(놓치지 않게).
- 메일은 읽기만 합니다. 읽음 표시·라벨을 바꾸지 않습니다.

| 형식 | 읽는 방법 |
|---|---|
| Google 문서·시트·슬라이드, docx, xlsx, hwpx, txt, csv | 텍스트로 읽어 규칙 → (필요 시) Claude |
| PDF, 이미지(jpg·png 등) | 이름에 키워드가 있을 때만 Claude로 보냄 |
| hwp(한글 바이너리) 등 | 읽지 못함 → 이름에 키워드가 있으면 "[직접 확인]" |

## 설치

1. [script.google.com](https://script.google.com)에서 **새 프로젝트**를 만듭니다(본인 계정).
2. 편집기 왼쪽 **프로젝트 설정 → "appsscript.json" 매니페스트 파일 표시**를 켭니다.
3. `src/` 폴더의 파일을 같은 이름으로 만들어 내용을 붙여 넣습니다(`appsscript.json` 포함, `.js`는 `.gs`로 만들어도 됩니다).
   - `clasp`를 쓴다면 `clasp create --rootDir src` 후 `clasp push`.
4. `Config.js`의 `COMPANY_NAME`을 실제 회사 이름으로 바꿉니다.
5. (선택) Claude API를 쓰려면 [Claude Console](https://console.anthropic.com)에서 API 키를 만들고 **프로젝트 설정 → 스크립트 속성**에 `ANTHROPIC_API_KEY`로 저장합니다. 구독(Pro·Max)과 별도로 쓴 만큼 과금됩니다. 키가 없어도 동작하며, 그때 규칙으로 못 정한 문서는 "[직접 확인]" 할 일이 됩니다.
6. 함수 `dryRun`을 실행합니다. 권한 승인 후 **실행 로그**에 만들 할 일이 표시됩니다. 실제로는 아무것도 만들지 않습니다.
7. 결과가 괜찮으면 `setup`을 실행합니다. 할 일 목록을 만들고 15분 트리거를 겁니다. 멈출 때는 `uninstall`.

처음 실행 때는 최근 7일(`FIRST_RUN_LOOKBACK_DAYS`) 변경분부터 봅니다.

## 업로더에게 확인 사실이 드러나지 않게

- **조회 기록 끄기**: 구글 문서 화면 **도구 → 활동 대시보드 → 개인정보 보호 설정 → 조회 기록 표시**를 끕니다. 관리 콘솔(앱 → Google Workspace → 드라이브 및 문서)에서 사용자가 이 설정을 바꿀 수 있게 허용돼 있어야 합니다.
- **설치 후 한 번 확인**: 이 스크립트는 Drive API로 파일을 내려받습니다. 이것이 활동 대시보드에 "열람"으로 남는지는 확인하지 못했습니다. 다른 계정으로 테스트용 견적서 문서를 공유 드라이브에 올리고, `dryRun` 실행 뒤 그 계정에서 문서의 활동 대시보드를 열어 내 이름이 보이는지 확인하세요.
- **공유 드라이브 멤버 추가 주의**: 이 스크립트는 **내가 멤버인** 공유 드라이브만 봅니다. 다른 드라이브를 보려고 나를 멤버로 추가하면 멤버 목록에 이름이 보입니다.
- Workspace 관리자 감사 로그에는 접근 기록이 남습니다(관리자 본인만 봄).

## 알아둘 한계

- **규칙 추출은 돈의 방향을 모릅니다.** 우리 회사가 발행한(돈을 받는) 견적서도 지급 할 일로 잡힐 수 있습니다. 규칙으로 만든 할 일은 메모에 "추출 방식: 규칙(원문 확인 권장)"이 붙습니다. Claude 추출은 `COMPANY_NAME`으로 방향을 가립니다.
- 이름에 키워드가 없는 PDF·스캔본은 비용을 아끼려고 열지 않습니다. 놓치는 게 있으면 `NAME_KEYWORDS`에 단어를 추가하세요.
- Claude API 비용은 PDF 기준 문서당 약 $0.05~0.1로 추정합니다(실측 아님). 정확도가 아쉬우면 `EFFORT`를 `'medium'`으로 올리세요.
- 처리 기록은 스크립트 속성에 180일간 보관합니다.

## 테스트

Google 서비스를 흉내 낸 Node 테스트입니다(실제 Google·Claude API는 호출하지 않음).

```bash
python3 test/make_fixtures.py   # 테스트 문서 다시 만들 때만 (python-docx, openpyxl 필요)
node --test test/run.test.js     # Node 18+
```
